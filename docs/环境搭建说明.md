## 三、Maven 未加入 PATH 的处理

`mvn` 命令在终端直接调用会提示 `command not found`。两种解决方式：

### 方式一：在 VS Code 中使用 Maven 面板（推荐）

左侧边栏找到 Maven 图标 → 展开 `lostfound` → `Lifecycle` → 双击 `spring-boot:run` 即可启动。

无需配置 PATH，图形化操作。

### 方式二：把 Maven 加入 PATH（一次配置，长期有效）

1. <kbd>Win</kbd> + <kbd>R</kbd> 输入 `sysdm.cpl` 回车
2. 「高级」→「环境变量」
3. 在「系统变量」中找到 `Path`，点「编辑」
4. 新增一行：

```
C:\Users\de\.m2\wrapper\dists\apache-maven-3.8.5-bin\5i5jha092a3i37g0paqnfr15e0\apache-maven-3.8.5\bin
```

5. 确定后**重启 VS Code**（必须重启才能生效）

### 同时建议设置 JAVA_HOME

同样在「系统变量」中点「新建」：

- 变量名：`JAVA_HOME`
- 变量值：`C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot`

并在 `Path` 中确保 JDK 17 的 `bin` 排在 JDK 23 之前，否则默认仍会用 23。

## 四、启动步骤

### 1. 启动后端

```bash
cd backend
mvn spring-boot:run -Dspring-boot.run.arguments=--server.port=8080
```

> 必须带 `--server.port=8080` 参数，原因见上方「重要提示」（环境变量 `SERVER__PORT` 覆盖）。

或在 VS Code 中打开 `LostFoundApplication.java` 点 ▷ 运行（需在
`.vscode/launch.json` 中配置 `args: ["--server.port=8080"]`）。

启动成功后访问：<http://localhost:8080/api/health>

应返回：

```json
{
  "code": 20000,
  "message": "后端连接成功",
  "data": {
    "status": "UP",
    "service": "校园失物招领管理系统",
    "version": "0.0.1-SNAPSHOT",
    "time": "2026-10-12 19:20:00"
  }
}
```

### 2. 启动前端

```bash
cd frontend
npm install     # 首次运行
npm run dev
```

访问 <http://localhost:5173>，点击「测试后端连接」按钮。

**看到绿色的「后端连接成功」提示，说明整条链路已打通。**

## 五、常见问题

### Q1：后端启动报数据库连接失败

骨架阶段的健康检查接口**不依赖数据库**，但 Spring Boot 启动时会初始化 Druid 连接池。
需要先创建数据库：

```sql
CREATE DATABASE campus_lostfound DEFAULT CHARACTER SET utf8mb4;
```

或修改 `application.yml` 中的 `username` / `password` 为你的 MySQL 账号。

### Q2：前端 npm install 报 EBUSY

这是文件被占用（通常是杀毒软件实时扫描）导致的。处理方式：
关闭杀毒软件的实时防护后重试，或直接重新执行 `npm install`（npm 会自动续装）。

**注意 —— 这个中断会留下后遗症**：npm 在安装「平台专用可选依赖」时被中断，
会导致 `@rollup/rollup-win32-x64-msvc` 和 `@esbuild/win32-x64` 这类包**静默漏装**。
表现为启动时报 `Cannot find module @rollup/rollup-win32-x64-msvc` 或
`The package "@esbuild/win32-x64" could not be found`。

**修复方式**（本项目已修复）：

```bash
cd frontend
npm install @rollup/rollup-win32-x64-msvc@<rollup版本> --no-audit --no-fund
npm install @esbuild/win32-x64@<esbuild版本> --no-audit --no-fund
```

版本号需与 `node_modules/rollup/package.json` 和 `node_modules/esbuild/package.json`
中的 `version` 字段保持一致。本项目实测：rollup `4.64.5`、esbuild `0.21.5`。

彻底解法：删除 `package-lock.json` 和 `node_modules` 后重新 `npm install`，
但删目录操作风险较高，建议优先用上面的精确安装方式。

### Q5：curl 测试本地接口返回 502 / 连接被拒绝

本机设置了 `http_proxy` / `https_proxy` 环境变量（指向 `127.0.0.1:2141`），
`curl` 默认会走代理，导致本地请求被拦截。

测试本地接口时加 `--noproxy` 参数：

```bash
curl --noproxy "*" http://127.0.0.1:8080/api/health
```

浏览器访问 `localhost` **不受影响**（浏览器一般会绕过代理访问本地地址）。

### Q6：前端只监听 IPv6

Vite 默认可能只绑定 `[::1]`。用 `http://localhost:5173` 或 `http://[::1]:5173`
访问即可；若要用 `127.0.0.1` 访问，可在 `vite.config.js` 中设置
`server.host: '0.0.0.0'`。

### Q3：VS Code 中 Java 代码报红

按 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>，输入 `Java: Clean Java Language Server Workspace`，
选择 Restart and delete。语言服务器会重新索引项目。

### Q4：如何切换 JDK 版本

在 VS Code 设置中搜索 `java.configuration.runtimes`，或在项目根目录创建
`.vscode/settings.json`：

```json
{
  "java.configuration.runtimes": [
    {
      "name": "JavaSE-17",
      "path": "C:\\Program Files\\Eclipse Adoptium\\jdk-17.0.20.101-hotspot",
      "default": true
    }
  ]
}
```
